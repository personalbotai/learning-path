### 1. Konsep & Arsitektur Mendalam

Di dalam Dart, fungsi adalah warga kelas satu (*first-class citizens*). Artinya, sebuah fungsi merupakan objek bertipe `Function` yang dapat disimpan ke dalam variabel, diteruskan sebagai argumen ke fungsi lain, atau dikembalikan sebagai *return value*. Fungsi yang menerima fungsi lain sebagai parameter atau mengembalikannya disebut sebagai **Higher-Order Functions (HOF)**.

Pada ekosistem koleksi Dart (`Iterable<E>`), HOF menjadi fondasi pemrograman deklaratif (*declarative/functional data processing*). Operasi seperti `map`, `where`, `fold`, `reduce`, `any`, dan `every` diimplementasikan sebagai *extension methods* atau *instance methods* pada antarmuka abstrak `Iterable<E>`.

```
                    ┌─────────────────────────┐
                    │       Iterable<E>       │
                    └────────────┬────────────┘
         ┌──────────────────────┼──────────────────────┐
         ▼                      ▼                      ▼
┌──────────────────┐  ┌──────────────────┐  ┌─────────────────────┐
│ Transformation   │  │    Filtering     │  │     Aggregations    │
│  - map<T>()      │  │  - where()       │  │  - fold<T>()        │
│  (Lazy Pipeline) │  │  (Lazy Pipeline) │  │  - reduce()         │
└──────────────────┘  └──────────────────┘  │  - any() / every()  │
                                            │  (Eager/Terminal)   │
                                            └─────────────────────┘
```

Secara garis besar, metode-metode ini terbagi menjadi dua kategori operasional:

1. **Lazy Operations (Pipeline/Intermediate)**:
   - `map<T>((E) -> T)`: Mengubah setiap elemen tipe `E` menjadi elemen tipe `T`.
   - `where((E) -> bool)`: Menyaring elemen berdasarkan predikat boolean.
   *Karakteristik:* Metode ini **tidak** mengeksekusi komputasi secara instan saat dipanggil. Sebaliknya, mereka mengembalikan instans pembungkus (*wrapper*) seperti `MappedIterable` atau `WhereIterable` yang menunda eksekusi hingga data diminta melalui traversal.

2. **Eager / Terminal Operations**:
   - `fold<T>(T initialValue, (T, E) -> T)`: Mengakumulasi elemen secara sekuensial dengan nilai awal eksplisit. Tipe akumulator `T` bebas dan tidak harus sama dengan tipe elemen `E`.
   - `reduce((E, E) -> E)`: Mirip dengan `fold`, namun menggunakan elemen pertama sebagai nilai awal dan memerlukan tipe akumulator yang identik dengan elemen koleksi.
   - `any((E) -> bool)` & `every((E) -> bool)`: Operasi pencarian linier dengan evaluasi *short-circuit* (berhenti segera setelah kondisi terminasi terpenuhi).

### 2. Implementasi & Contoh Kasus Nyata

Skenario: Pemrosesan transaksi keuangan pada *e-commerce checkout engine*. Sistem perlu memvalidasi status pesanan, memfilter item non-digital, menghitung total biaya transaksi, serta melakukan audit keamanan batas transaksi.

```dart
enum ProductType { digital, physical }

class OrderItem {
  final String id;
  final String title;
  final double price;
  final int quantity;
  final ProductType type;

  const OrderItem({
    required this.id,
    required this.title,
    required this.price,
    required this.quantity,
    required this.type,
  });

  double get subtotal => price * quantity;
}

void main() {
  final List<OrderItem> cart = [
    const OrderItem(id: 'A1', title: 'E-Book Architecture', price: 150000, quantity: 1, type: ProductType.digital),
    const OrderItem(id: 'B2', title: 'Mechanical Keyboard', price: 1200000, quantity: 1, type: ProductType.physical),
    const OrderItem(id: 'C3', title: 'USB-C Cable', price: 45000, quantity: 2, type: ProductType.physical),
    const OrderItem(id: 'D4', title: 'Video Course Access', price: 300000, quantity: 1, type: ProductType.digital),
  ];

  // 1. WHERE: Memfilter hanya barang fisik yang memerlukan ongkos kirim
  final Iterable<OrderItem> physicalItems = cart.where(
    (item) => item.type == ProductType.physical,
  );

  // 2. MAP: Mengambil array subtotal dari barang fisik
  final Iterable<double> physicalSubtotals = physicalItems.map(
    (item) => item.subtotal,
  );

  // 3. FOLD: Menghitung total biaya barang fisik dengan base handling fee (misal: 10.000)
  // fold fleksibel karena tipe kembalian bisa berbeda dari tipe elemen
  const double baseHandlingFee = 10000.0;
  final double totalPhysicalCost = physicalItems.fold<double>(
    baseHandlingFee,
    (runningTotal, item) => runningTotal + item.subtotal,
  );

  // 4. REDUCE: Menemukan item tunggal termahal di dalam keranjang
  // PERINGATAN: reduce akan melempar StateError jika list kosong
  final OrderItem mostExpensiveItem = cart.reduce(
    (currentMax, item) => item.price > currentMax.price ? item : currentMax,
  );

  // 5. ANY: Validasi apakah ada item dengan nilai di atas batas audit regulasi (misal: >= 1.000.000)
  // Short-circuit: Berhenti evaluasi begitu B2 ditemukan.
  final bool requiresSupervisorApproval = cart.any(
    (item) => item.price >= 1000000,
  );

  // 6. EVERY: Memastikan semua item memiliki kuantitas valid (> 0)
  final bool isCartValid = cart.every(
    (item) => item.quantity > 0,
  );

  // Output Hasil
  print('Barang Fisik: ${physicalItems.map((e) => e.title).toList()}');
  print('Subtotal Barang Fisik: ${physicalSubtotals.toList()}');
  print('Total Biaya Fisik (+ Handling): Rp$totalPhysicalCost');
  print('Item Termahal: ${mostExpensiveItem.title} (Rp${mostExpensiveItem.price})');
  print('Perlu Approval Supervisor: $requiresSupervisorApproval');
  print('Integritas Keranjang Valid: $isCartValid');
}
```

### 3. Cara Kerja di Balik Layar (Under the Hood)

#### Eksekusi & Runtime: *Lazy Evaluation Chains*
Ketika Anda memanggil `.where(...)` atau `.map(...)`, Dart **tidak** mengalokasikan array baru atau menjalankan *loop*.
```dart
final stream = list.where(predicate).map(transform);
```
- Pemanggilan `where` mengembalikan instans kelas internal `WhereIterable<E>`.
- Pemanggilan `map` di atasnya mengembalikan instans `MappedIterable<E, T>`.
- Evaluasi baru berjalan ketika pemanggil mengeksekusi operasi terminal seperti `.toList()`, loop `for-in`, `reduce`, atau `fold`.

Saat `.iterator.moveNext()` dipanggil pada pipeline tersebut:
1. `MappedIterable` mendelegasikan pemanggilan `moveNext()` ke `WhereIterable`.
2. `WhereIterable` melakukan iterasi pada koleksi asli hingga menemukan elemen yang memenuhi predikat `bool`.
3. Setelah elemen ditemukan, `MappedIterable` mengaplikasikan fungsi transformasi `transform(element)` dan mengembalikannya ke konsumen.

#### Alokasi Memori & Resource
- **Heap Overhead pada Closures**: Setiap lambda/closure anonim (misal: `(e) => e.price > 100`) mengalokasikan konteks closure pada *heap* jika ia menangkap variabel dari *outer scope* (*lexical scoping*). Jika tidak ada variabel luar yang ditangkap, Dart VM/AOT compiler dapat mengoptimalkannya sebagai statik atau melakukan *closure tearing*.
- **Chained Iterators Allocation**: Menghubungkan 5 HOF lazy berturut-turut menciptakan 5 wrapper object di heap sebelum iterasi sesungguhnya dimulai. Hindari pipeline terlalu dalam pada *critical rendering path* (misal: method `build()` Flutter atau frame render loop 120 FPS).

#### Trade-offs: `fold` vs `reduce`
- **`fold`**:
  - *Safety*: Aman untuk koleksi kosong karena mengembalikan `initialValue`.
  - *Flexibility*: Tipe output ($T$) independen dari tipe koleksi ($E$).
- **`reduce`**:
  - *Risks*: Melemparkan `StateError: No element` jika diterapkan pada koleksi kosong.
  - *Constraints*: Tipe kembalian harus *subtype* dari elemen koleksi ($T \subseteq E$).

### 4. Best Practices & Common Pitfalls

#### Do's:
- **Gunakan *Tear-offs* daripada Lambdas redundant**:
  ```dart
  // Buruk: Alokasi closure yang tidak perlu
  items.map((item) => item.toString());
  
  // Baik: Gunakan tear-off method/property
  items.map((e) => e.title); // Jika property
  strings.map(int.parse);    // Function tear-off langsung
  ```
- **Prioritaskan `fold` daripada `reduce`**: Terutama ketika sumber data berasal dari API dinamis di mana ukuran list bisa saja 0.
- **Konsumsi hasil Lazy Pipeline secara cermat**: Jika Anda berencana menggunakan hasil pipeline berkali-kali, akhiri dengan `.toList()` atau `.toSet()` untuk mem-**persist** hasil evaluasi di memori.

#### Don'ts:
- **Hindari *Side-Effects* di dalam `map` atau `where`**:
  HOF adalah representasi pemrograman fungsional. Memodifikasi *global state* atau variabel luar di dalam HOF menyebabkan bug laten akibat eksekusi lazy.
  ```dart
  // ANTI-PATTERN: Side-effect di dalam map
  int counter = 0;
  final result = items.map((e) {
    counter++; // SANGAT DIHINDARI: Kapan dieksekusi? Berapa kali?
    return e.price;
  });
  // Jika result tidak pernah di-iterate, counter tetap 0!
  ```
- **Jangan Iterasi Berulang pada Lazy Chain**:
  ```dart
  final filtered = list.where((x) => x.isValid); // Lazy
  
  print(filtered.length); // Iterasi #1 terjadi
  print(filtered.first);  // Iterasi #2 terjadi dari awal lagi!
  
  // SOLUSI:
  final materialized = list.where((x) => x.isValid).toList();
  ```

#### Edge Cases:
- **Evaluasi Kosong pada `reduce`**:
  ```dart
  final List<int> emptyList = [];
  emptyList.reduce((a, b) => a + b); // THROWS Bad state: No element
  ```
- **Trik Identitas Boolean `any` vs `every` pada Koleksi Kosong**:
  - `[].any(predicate)` selalu menghasilkan `false` (karena tidak ada satupun elemen yang memenuhi predikat).
  - `[].every(predicate)` selalu menghasilkan `true` (*Vacuous truth* dalam logika matematika).

### 5. Tantangan Eksplorasi Mandiri

1. **Membedah *Re-computation Penalty***:
   Buat sebuah `List<int>` berisi 1.000.000 angka acak. Buat rantai `.where((x) => x.isEven).map((x) => x * 2)`. Hitung durasi eksekusi menggunakan `Stopwatch` ketika Anda memanggil `.length`, `.first`, dan `.last` secara langsung dari objek *Iterable* hasil filter tanpa melakukan `.toList()`. Bandingkan hasilnya jika Anda menyimpannya ke variabel via `.toList()` terlebih dahulu.
2. **Kustomisasi `reduce` yang Aman (*Safe Reduce*)**:
   Implementasikan *extension method* generik `reduceOrNull()` pada `Iterable<E>`. Metode ini harus berperilaku persis seperti `reduce`, namun mengembalikan `null` alih-alih melempar `StateError` saat koleksi dalam keadaan kosong.
3. **Rekonstruksi Mesin Internal**:
   Tulis ulang fungsi `myWhere` dan `myMap` Anda sendiri tanpa menggunakan fungsi bawaan Dart, menggunakan konsep class `Iterator<T>` kustom yang mengimplementasikan `moveNext()` dan properti `current`. Pastikan implementasi Anda bersifat *lazy*.
