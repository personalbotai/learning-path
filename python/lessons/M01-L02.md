## Tujuan Pembelajaran
Write your first Python script, understand indentation rules, comments, and basic program structure.

## Materi

### Konsep Dasar
Python menggunakan indentation (spasi atau tab) untuk menentukan blok kode, bukan kurung kurawal seperti bahasa lain. Standar PEP 8 merekomendasikan 4 spasi per level indentasi. Indentation yang konsisten sangat penting karena akan menyebabkan error jika tidak sesuai.

Komentar di Python dimulai dengan `#` dan berlaku sampai akhir baris. Komentar berguna untuk menjelaskan kode kepada pembaca manusia. Python tidak memiliki sintaks untuk komentar multi-baris seperti `/* */` di C, tetapi kita bisa menggunakan string literal yang tidak ditugaskan untuk komentar multi-baris.

Program Python paling sederhana adalah "Hello World" yang hanya berisi satu baris `print("Hello World")`. Script Python biasanya memiliki ekstensi `.py` dan dapat dijalankan dengan perintah `python script.py`. Struktur program dapat mencakup import statements, function definitions, dan kode yang dieksekusi langsung.

### Detail Teknis
- Gunakan 4 spasi untuk indentasi, jangan gunakan tab
- Komentar sebaiknya ditulis dengan jelas dan singkat
- Script Python dapat dijalankan dari terminal atau IDE
- Gunakan `if __name__ == "__main__":` untuk mencegah kode berjalan saat di-import


### Deep Dive: CPython Compilation Pipeline & Execution
Bagaimana Python menjalankan kode Anda? Python adalah *interpreted bytecode language*:

1. **Lexing & Parsing**: Kode sumber `.py` diubah menjadi Abstract Syntax Tree (AST).
2. **Bytecode Compilation**: AST dikompilasi menjadi CPython bytecode (instruksi tingkat rendah tersimpan dalam file cache `.pyc` di folder `__pycache__`).
3. **CPython Virtual Machine (PVM)**: Evaluasi loop raksasa (`ceval.c`) yang mengeksekusi instruksi bytecode satu per satu.

```
Source Code (.py) ──► Tokenizer ──► AST ──► Bytecode (.pyc) ──► CPython VM (PVM)
```

### Aturan Indentasi PEP 8 & Whitespace
Indentasi di Python bukan sekadar estetika, melainkan penentu struktur blok logika:
- Standar resmi: **4 spasi per level indentasi** (jangan mencampur tab dan spasi).
- Tabulasi dapat menghasilkan `TabError: inconsistent use of tabs and spaces in indentation`.
- Baris kosong (blank lines): Gunakan 2 baris kosong di antara fungsi/class tingkat atas, dan 1 baris kosong di dalam class method.

### Best Practices & Konvensi Industri
- Gunakan formatter otomatis seperti **Black** atau **Ruff** untuk menjaga konsistensi gaya kode.
- Tulis komentar untuk menjelaskan **alasan (why)** kode dibuat seperti itu, bukan mendeskripsikan ulang apa yang sudah jelas dari sintaks (what).
- Manfaatkan docstrings (`"""..."""`) untuk dokumentasi modul dan fungsi.

### Common Pitfalls & Antipatterns
- Menggunakan tab di satu file dan spasi di file lain.
- Memberi komentar berlebihan untuk hal-hal sepele seperti `x = 5  # isi x dengan 5`.

## Latihan

### Soal 1
Buat script Python yang menampilkan "Hello, World!" di terminal, lalu modifikasi untuk menampilkan nama kamu.

```python
def latihan_1():
    # Tulis kode kamu di sini
    pass

if __name__ == "__main__":
    latihan_1()
```

**Expected Output**:
```
Hello, World!
Hello, [Nama Kamu]!
```

### Soal 2
Buat script yang menampilkan pola bintang sederhana dengan menggunakan print dan string multiplication.

```python
def latihan_2():
    # Tulis kode kamu di sini
    pass

if __name__ == "__main__":
    latihan_2()
```

**Expected Output**:
```
*
**
***
****
*****
```
