## Materi

### Konsep Dasar
Statement `if` digunakan untuk eksekusi bersyarat. Sintaksnya:
```python
if kondisi:
    # kode jika True
elif kondisi_lain:
    # kode jika True
else:
    # kode jika semua False
```
`elif` opsional, bisa banyak. `else` juga opsional. Kondisi berupa expression yang dievaluasi ke boolean. Python menggunakan indentasi untuk blok.

Operator perbandingan: `==`, `!=`, `<`, `>`, `<=`, `>=`. Gabungan dengan `and`, `or`, `not`. Nested if dimungkinkan tapi harus hati-hati agar tidak terlalu dalam (spaghetti code). Ternary operator: `x if condition else y`.

### Detail Teknis
- Python tidak memiliki switch statement, gunakan if-elif
- Perbandingan string dilakukan leksikografis
- Gunakan parentheses untuk memperjelas precedence
- Satu baris if: `if x > 0: print("positive")`


### Deep Dive: Branching Logic & Short-Circuit Evaluation
Python mengevaluasi ekspresi boolean secara *lazy* (short-circuit):
- Pada `A and B`, jika `A` bernilai falsy, Python tidak akan mengevaluasi `B`.
- Pada `A or B`, jika `A` bernilai truthy, Python langsung mengembalikan `A` tanpa mengevaluasi `B`.

### Konsep Truthiness di Python
Objek berikut bernilai **Falsy**:
- `None`, `False`
- Angka nol: `0`, `0.0`, `0j`
- Koleksi kosong: `""`, `[]`, `()`, `{}`, `set()`, `range(0)`
- Objek kustom yang mengembalikan `False` dari `__bool__()` atau `0` dari `__len__()`.

Semua nilai selain di atas bernilai **Truthy**. Oleh karena itu, kita sebaiknya menulis:
```python
if not items:  # Lebih Pythonic daripada 'if len(items) == 0:'
    print("List kosong")
```

### Best Practices & Konvensi Industri
- Terapkan **Guard Clauses (Early Return)** untuk menghindari nesting `if` bertingkat yang dalam (arrow anti-pattern).
- Gunakan perbandingan identitas `is` untuk `None` dan `is not None`, bukan operator persamaan `==`.
- Manfaatkan ekspresi kondisional ternary `hasil = a if kondisi else b` untuk penugasan nilai singkat.

### Common Pitfalls & Antipatterns
- Membandingkan boolean dengan `if is_admin == True:` alih-alih `if is_admin:`.
- Menggunakan `if x == None` alih-alih `if x is None`.

Buat fungsi yang menerima integer dan mengembalikan "positif" jika >0, "negatif" jika <0, atau "nol" jika sama dengan 0.

```python
def latihan_1(angka):
    # Tulis kode kamu di sini
    pass

if __name__ == "__main__":
    print(latihan_1(5))    # Output: positif
    print(latihan_1(-3))   # Output: negatif
    print(latihan_1(0))    # Output: nol
```

**Expected Output**:
```
positif
negatif
nol
```
