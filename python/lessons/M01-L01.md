## Tujuan Pembelajaran
Install Python 3.11+, configure IDE (VS Code/PyCharm), understand virtual environments with venv and pip.

## Materi

### Konsep Dasar
Python adalah bahasa pemrograman yang perlu diinstal di sistem kita sebelum bisa digunakan. Versi terbaru saat ini adalah Python 3.11 atau lebih. Proses instalasi melibatkan download dari python.org dan memastikan Python ditambahkan ke PATH environment variable. Setelah instalasi, kita bisa mengakses Python melalui terminal dengan perintah `python` atau `python3`.

Virtual environment adalah cara untuk mengisolasi dependencies proyek Python. Setiap proyek bisa memiliki versi library yang berbeda tanpa konflik. Python menyediakan modul `venv` yang bisa membuat lingkungan virtual dengan menjalankan `python -m venv myenv`. Setelah dibuat, kita mengaktifkannya dengan `source myenv/bin/activate` di Linux/Mac atau `myenv\Scripts\activate` di Windows.

Package manager `pip` adalah alat untuk menginstall dan mengelola package Python. Setelah virtual environment aktif, kita bisa install package dengan `pip install package_name`. Perlu diingat bahwa selalu gunakan virtual environment untuk setiap proyek agar dependencies tetap terisolasi.

### Detail Teknis
- Download Python dari python.org dan pilih checkbox "Add Python to PATH" saat instalasi
- Buat virtual environment dengan `python -m venv nama_env` dan aktivasi sesuai OS
- Gunakan `pip freeze > requirements.txt` untuk mengeksport dependencies dan `pip install -r requirements.txt` untuk install dari file


### Deep Dive: Arsitektur Python Virtual Environment & PATH
Ketika Anda menjalankan perintah `python` atau `pip`, sistem operasi mencari executable tersebut berdasarkan urutan direktori yang terdaftar di variabel lingkungan `PATH`.

1. **Struktur Virtual Environment (`venv`)**:
   - `bin/` (Linux/macOS) atau `Scripts/` (Windows): Berisi symlink atau salinan biner `python`, `pip`, serta script aktivasi (`activate`).
   - `lib/python3.x/site-packages/` (Linux/macOS) atau `Lib\site-packages\` (Windows): Tempat di mana seluruh library pihak ketiga (third-party packages) diinstal secara terisolasi.
   - `pyvenv.cfg`: Berisi konfigurasi dasar seperti `home = /usr/bin` dan `include-system-site-packages = false`.

2. **Perbedaan `pip install` vs `python -m pip install`**:
   Sangat disarankan menggunakan sintaks `python -m pip install <package>` karena ini menjamin package akan diinstal ke environment yang dimiliki oleh executable `python` yang sedang aktif saat itu, menghindari konflik saat ada beberapa versi Python di sistem.

3. **Modern Packaging Tools**:
   Selain `venv` bawaan, ekosistem modern Python sering menggunakan tools tingkat lanjut:
   - **Poetry / Hatch**: Manajemen dependency berbasis standar `pyproject.toml` (PEP 517/518/621).
   - **uv**: Package installer dan resolver ultra-cepat yang ditulis dalam Rust oleh Astral.
   - **Conda / Mamba**: Ideal untuk ekosistem data science dengan dependensi C/C++ dan CUDA binary.

### Best Practices & Konvensi Industri
- **Jangan pernah install package secara global** tanpa virtual environment kecuali untuk system tools terisolasi (gunakan `pipx`).
- **Sertakan `.venv/` atau `venv/` ke dalam `.gitignore`** agar direktori lingkungan lokal tidak ter-commit ke git repository.
- **Pin dependency versions** di file produksi (`requirements.lock` atau `requirements.txt` dengan hash).

### Common Pitfalls & Antipatterns
- **Lupa mengaktifkan virtual environment**: Menyebabkan instalasi paket masuk ke environment global atau gagal permission.
- **Mencampuradukkan Python 2 dan Python 3**: Pastikan selalu memanggil `python3` jika perintah `python` di sistem Anda masih menunjuk ke versi lawas.

Instal Python 3.11+ di sistem kamu dan buat virtual environment baru. Setelah itu, install package `requests` dan buat file `requirements.txt`.

**Expected Output**:
File `requirements.txt` berisi daftar package termasuk requests dengan versinya.

### Soal 2
Buat script Python yang menampilkan versi Python yang sedang digunakan dan daftar package yang terinstall di virtual environment saat ini.

```python
import sys
import pkg_resources

def latihan_2():
    print(f"Python version: {sys.version}")
    print("\nInstalled packages:")
    for dist in sorted(pkg_resources.working_set, key=lambda x: x.project_name.lower()):
        print(f"{dist.project_name}=={dist.version}")

if __name__ == "__main__":
    latihan_2()
```

**Expected Output**:
```
Python version: 3.11.x (tanggal dan build info)
Installed packages:
certifi==x.x.x
charset-normalizer==x.x.x
idna==x.x.x
pip==x.x.x
requests==x.x.x
... (package lainnya)
```
