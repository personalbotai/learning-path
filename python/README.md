## ✨ Features

- 💻 **Lazy-Loaded Pyodide WASM:** Run Python 3.12+ code directly inside your browser with near-instant initial page loads (WASM runtime downloads on-demand upon first run).
- 📖 **55 Curated Lessons:** Comprehensive roadmap from language syntax to advanced concepts, OOP, data structures, and async programming.
- 🎯 **Deep Technical Engineering Quizzes:** Interactive multiple-choice quizzes with detailed Indonesian explanations and edge-case insights.
- 🎖️ **Graduation Certificate Generator:** High-resolution Canvas certificate generator with PNG & PDF export — gated strictly to 100% course completion.
- 📱 **PWA & Offline Support:** Service Worker offline caching and Web App Manifest for a seamless app-like mobile experience.
- 💾 **Auto-Resume & State Persistence:** Remembers your exact lesson and completion progress in `localStorage`.
- 🌓 **Adaptive Theme & Mobile UX:** Dark/light mode toggle with expandable animated search and responsive navigation.

## 📚 Curriculum Overview

1. **Python Foundations** — Variables, primitive types, operators, dynamic typing, and virtual environments.
2. **Control Flow** — Conditionals, structural pattern matching (`match-case`), loops, and iterators.
3. **Data Structures** — Lists, tuples, dictionaries, sets, comprehensions, and memory immutability.
4. **Functions & Modularization** — LEGB scope, `*args`/`**kwargs`, lambda, closures, and decorators.
5. **Object-Oriented Programming** — Classes, inheritance, polymorphism, dunder methods, and dataclasses.
6. **Error Handling & Files** — `try-except-finally`, custom exceptions, file I/O, and context managers.
7. **Modern Standard Library** — `math`, `datetime`, `collections`, `itertools`, `pathlib`, `json`.
8. **Advanced Concepts** — Generators, async/await concurrency, type hinting, and package management.

## 🛠️ Local Development

Clone and run locally with any static file server:

```bash
git clone https://github.com/personalbotai/python-learning-path.git
cd python-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
