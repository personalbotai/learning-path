## 📖 Materi Lengkap

### 1. Konsep & Arsitektur Mendalam

Dalam PHP modern (versi 7.4 hingga 8.x), fungsi telah berevolusi dari sekadar blok kode prosedural menjadi entitas yang sangat terstruktur dengan *strong typing*, fleksibilitas pemanggilan, dan sintaks yang ringkas. 

- **Fungsi (Functions & Closures):** Di PHP, fungsi anonim (anonymous functions) diimplementasikan sebagai instance dari kelas internal `Closure`. Ini berarti fungsi dapat diperlakukan sebagai *first-class citizen* (bisa disimpan dalam variabel, dilempar sebagai argumen, atau dikembalikan dari fungsi lain).
- **Named Arguments (PHP 8.0+):** Fitur ini memungkinkan pengiriman argumen ke fungsi berdasarkan nama parameternya, bukan posisinya. Ini memecahkan masalah *boolean trap* (misalnya `sendEmail($to, true, false)`) dan mengeliminasi keharusan mengisi parameter opsional hanya untuk mencapai parameter di urutan akhir.
- **Arrow Functions (PHP 7.4+):** Sintaks pendek (`fn() => ...`) untuk *anonymous functions*. Berbeda dengan *closure* biasa yang memerlukan kata kunci `use` untuk mengimpor variabel dari *outer scope*, arrow function melakukan *auto-capture* variabel secara otomatis berdasarkan *lexical scope*.

### 2. Implementasi & Contoh Kasus Nyata

```php
<?php
declare(strict_types=1);

// 1. Fungsi Modern dengan Type Hinting (Union Types & Return Types)
function createSubscription(
    string $userId,
    string|int $planId,
    bool $isAnnual = false,
    float $discount = 0.0,
    string $currency = 'IDR'
): array {
    return [
        'user' => $userId,
        'plan' => $planId,
        'annual' => $isAnnual,
        'total' => $isAnnual ? (100000 * 12) - $discount : 100000 - $discount,
        'currency' => $currency
    ];
}

// Menggunakan Named Arguments: Urutan tidak penting, parameter opsional bisa dilewati
$subscription = createSubscription(
    planId: 99,
    userId: 'USR-123',
    discount: 50000.0 // Melewati $isAnnual, langsung ke $discount
);

// 2. Arrow Functions vs Anonymous Functions
$multiplier = 1.11; // PPN 11%
$prices = [10000, 25000, 50000];

// Cara lama (Closure biasa): Harus eksplisit menggunakan 'use'
$taxedOld = array_map(function(int $price) use ($multiplier): float {
    return $price * $multiplier;
}, $prices);

// Cara modern (Arrow Function): Auto-capture $multiplier, sintaks lebih bersih
$taxedNew = array_map(fn(int $price): float => $price * $multiplier, $prices);

// 3. Variadic Functions & Argument Unpacking dengan Named Arguments
function logEvents(string $level, ...$events): void {
    foreach ($events as $event) {
        echo "[$level] $event\n";
    }
}

// Unpacking array asosiatif sebagai Named Arguments (PHP 8.0+)
$config = [
    'userId' => 'USR-999',
    'planId' => 'PRO',
    'isAnnual' => true
];
$sub2 = createSubscription(...$config); 
```

### 3. Cara Kerja di Balik Layar (Under the Hood)

- **Eksekusi & Runtime**: Saat Zend Engine (ZE) mengkompilasi skrip PHP, fungsi didefinisikan dan disimpan dalam *Function Table* (sebuah Hash Table internal). Saat pemanggilan fungsi terjadi, ZE membuat *stack frame* baru. Untuk *Named Arguments*, pada fase kompilasi/runtime, ZE akan memetakan nama argumen yang diberikan ke posisi parameter yang sesuai di *Function Table*. Jika nama tidak ditemukan, `Error` dilempar.
- **Alokasi Memori / Resource**: 
  - **Arrow Functions**: Melakukan *auto-capture* variabel dari *parent scope* secara **by-value** (bukan by-reference). Artinya, PHP melakukan penyalinan nilai (dengan mekanisme *Copy-on-Write* untuk efisiensi memori) pada saat arrow function **didefinisikan**, bukan saat dieksekusi. Anda tidak dapat memodifikasi variabel *outer scope* dari dalam arrow function.
  - **Closures**: Diinstansiasi sebagai objek dari kelas `Closure`. Memori dialokasikan di *heap* untuk menyimpan state dari variabel yang di-`use`.
- **Trade-offs**: Arrow function sangat efisien untuk *callback* satu baris, tetapi dibatasi hanya untuk satu ekspresi (tidak bisa menggunakan blok `{}`). Named arguments meningkatkan keterbacaan, tetapi menciptakan *tight coupling* antara pemanggil dan nama parameter.

### 4. Best Practices & Common Pitfalls

- **Do's**:
  - Selalu gunakan `declare(strict_types=1);` di awal file untuk memastikan tipe data argumen divalidasi secara ketat.
  - Gunakan *Named Arguments* saat memanggil fungsi dengan lebih dari 2 parameter, terutama jika terdapat parameter bertipe `bool` (menghindari *boolean trap*).
  - Gunakan *Arrow Functions* untuk operasi array fungsional seperti `array_map`, `array_filter`, dan `array_reduce`.
- **Don'ts**:
  - **JANGAN** mengubah nama parameter pada fungsi publik (API/Library) jika pengguna Anda mungkin menggunakan *Named Arguments*. Mengubah nama parameter (misal `$id` menjadi `$userId`) sekarang adalah **Breaking Change (BC)** di PHP 8+.
  - Hindari penggunaan *pass-by-reference* (`&$var`) kecuali benar-benar diperlukan (misal untuk optimasi memori ekstrem pada array raksasa). Ini membuat mutasi state sulit dilacak.
- **Edge Cases**:
  - Jika Anda mencampur *positional arguments* dan *named arguments*, *positional arguments* **harus** diletakkan sebelum *named arguments*. `foo(1, b: 2)` valid, `foo(a: 1, 2)` akan menghasilkan *Fatal Error*.
  - Arrow function dapat menggunakan `$this` secara otomatis jika didefinisikan di dalam sebuah method kelas.

### 5. Tantangan Eksplorasi Mandiri

1. Buatlah sebuah fungsi `calculateTotal` yang menerima parameter *variadic* berupa daftar harga (`...$prices`), lalu gunakan `array_reduce` dengan *Arrow Function* di dalamnya untuk menghitung total harga setelah dipotong diskon global yang diambil dari *outer scope*.
2. Rancang sebuah fungsi koneksi database dengan 5 parameter (host, user, password, dbname, port) di mana 3 parameter terakhir memiliki nilai default. Panggil fungsi tersebut menggunakan *Named Arguments* dengan hanya mengirimkan `host`, `user`, dan `port` (melewati password dan dbname). Coba lakukan *unpacking* menggunakan array asosiatif.
