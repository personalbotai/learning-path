### 1. Konsep & Arsitektur Mendalam

Di PHP, istilah "array" sebenarnya merupakan abstraksi tingkat tinggi. PHP tidak mengimplementasikan array linier contiguous seperti pada bahasa C atau Java primitive array. Di balik layar (Zend Engine), array PHP adalah sebuah **Ordered Hash Table** (kombinasi antara *hash map* dan *doubly-linked list*). Karakteristik utamanya meliputi:
1. **Penyimpanan Nilai Fleksibel**: Mampu menyimpan elemen bertipe data heterogen.
2. **Kunci Ganda**: Menerima kunci bertipe integer dan string secara bersamaan.
3. **Preservasi Urutan**: Mempertahankan urutan insersi (*insertion order*) terlepas dari tipe atau nilai kuncinya.

Sejak PHP 7.1, evolusi manipulasi array mengalami lompatan signifikan dengan diperkenalkannya **Array Destructuring** melalui sintaks kurung siku (`[...]`) sebagai pengganti konstruksi bahasa klasik `list()`. Fitur ini memungkinkan ekstraksi elemen array langsung ke variabel independen berbasis indeks numerik maupun kunci asosiatif. 

Pada PHP 8.1, kemampuan **Array Unpacking** (menggunakan *spread operator* `...`) diperluas untuk mendukung kunci bertipe `string`, menyelaraskan fungsionalitas spread dengan perilaku `array_merge()`, namun dengan eksekusi level opcode yang lebih optimal.

Pemisahan tanggung jawab antara manipulasi fungsional (`array_map`, `array_filter`, `array_reduce`) dan manipulasi struktural destruktif/non-destruktif menjadi fondasi utama dalam menulis kode PHP modern yang bersih, deklaratif, dan berperforma tinggi.

### 2. Implementasi & Contoh Kasus Nyata

Berikut adalah contoh skenario pemrosesan payload *Webhook Payment Gateway*. Kode ini mendemonstrasikan manipulasi array lanjutan, *nested array destructuring*, pemisahan *rest elements*, serta manipulasi data imutabel.

```php
<?php

declare(strict_types=1);

/**
 * Simulasi Payload Webhook dari Payment Gateway.
 */
$payload = [
    'event_id' => 'evt_99824f11a',
    'timestamp' => 1717982400,
    'data' => [
        'transaction' => [
            'id' => 'trx_01HZ8P',
            'amount' => 1500000,
            'currency' => 'IDR',
        ],
        'customer' => [
            'name' => 'Budi Pratama',
            'email' => 'budi.pratama@example.com',
            'metadata' => [
                'tier' => 'platinum',
                'referred_by' => 'aff_8812',
            ],
        ],
    ],
    'signature' => 'e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855',
];

// 1. Nested Destructuring dengan Pengubahan Nama Variabel (Key Aliasing)
[
    'event_id' => $eventId,
    'data' => [
        'transaction' => [
            'id' => $transactionId,
            'amount' => $rawAmount,
            'currency' => $currency,
        ],
        'customer' => [
            'name' => $customerName,
            'metadata' => ['tier' => $tier], // Ekstraksi parsial langsung ke sub-level
        ],
    ],
] = $payload;

echo "Event: {$eventId} | Trx: {$transactionId} | Customer: {$customerName} ({$tier})\n";

// 2. Manipulasi Array Koleksi dengan Pendekatan Fungsional
$lineItems = [
    ['sku' => 'LAPTOP-PRO', 'price' => 12000000, 'qty' => 1, 'taxable' => true],
    ['MOUSE-WL', 'price' => 350000, 'qty' => 2, 'taxable' => true], // Mixed key format
    ['WARRANTY-EXT', 'price' => 500000, 'qty' => 1, 'taxable' => false],
];

// Filter item kena pajak, kemudian hitung subtotal via array_reduce
$taxableTotal = array_reduce(
    array_filter($lineItems, static fn(array $item): bool => (bool)($item['taxable'] ?? false)),
    static fn(int $accumulated, array $item): int => $accumulated + ($item['price'] * $item['qty']),
    0
);

echo "Taxable Subtotal: IDR " . number_format($taxableTotal, 0, ',', '.') . "\n";

// 3. Array Unpacking (Spread Operator) pada Associative Array (PHP 8.1+)
$baseConfig = [
    'driver' => 'sqlsrv',
    'host' => '10.0.0.1',
    'port' => 1433,
    'timeout' => 30,
];

$overrideConfig = [
    'host' => 'prod-cluster.internal',
    'timeout' => 60,
    'pool_size' => 10,
];

// Array unpacking string-key: kunci duplikat di sisi kanan menimpa kunci di sisi kiri
$finalConfig = [
    ...$baseConfig,
    ...$overrideConfig,
    'app_name' => 'PaymentWorker',
];

print_r($finalConfig);

// 4. Destructuring Array Terindeks Numerik & Positional Swapping
$coordinates = [-6.2088, 106.8456]; // [lat, long]
[$latitude, $longitude] = $coordinates;

// Tukar posisi variabel tanpa temp variable via destructuring
[$longitude, $latitude] = [$latitude, $longitude];
echo "Swapped -> Lat: {$latitude}, Long: {$longitude}\n";
```

### 3. Cara Kerja di Balik Layar (Under the Hood)

#### Eksekusi & Runtime
Di level C-source Zend Engine (PHP Core), array direpresentasikan oleh struktur data `_zend_array` (sering disebut `HashTable`).
```c
struct _zend_array {
    zend_refcounted_h gc;
    union {
        struct {
            ZEND_ENDIAN_LOHI_4(
                zend_uchar    flags,
                zend_uchar    _unused,
                zend_uchar    nIteratorsCount,
                zend_uchar    _unused2)
        } v;
        uint32_t flags;
    } u;
    uint32_t          nTableMask;
    Bucket           *arData;
    uint32_t          nNumUsed;
    uint32_t          nNumOfElements;
    uint32_t          nTableSize;
    uint32_t          nInternalPointer;
    zend_long         nNextFreeElement;
    dtor_func_t       pDestructor;
};
```
Ketika opcode `FETCH_DIM_R` atau `ASSIGN_DIM` dijalankan, Zend Engine menggunakan fungsi hashing (DJBX33A) untuk memetakan kunci string menjadi indeks hash, lalu melakukan masking (`h | nTableMask`) untuk mendapatkan offset pada tabel perantara (*intermediate translation table*).

#### Alokasi Memori: Packed Array vs. Hash Array
PHP 7+ menerapkan optimasi internal signifikan yang membedakan dua layout penyimpanan array di dalam memori:
1. **Packed Array**: Jika array murni berupa daftar indeks numerik terurut secara menaik berurutan dari `0` sampai `N-1` (seperti format list vektor). PHP menonaktifkan kalkulasi hash mask dan *translation table*. Data disimpan langsung secara contiguous di memori `arData`. Ini menghemat memori hingga 50% dan meningkatkan *CPU cache locality*.
2. **Hash Array (Associative)**: Ketika terdapat kunci bertipe string, indeks integer non-sekuensial, atau operasi *unsetting*, array akan bermutasi (*escalate*) menjadi format Hash Array penuh yang mengalokasikan tabel dereferensi bucket tambahan.

#### Copy-on-Write (CoW)
Array di PHP bersifat *pass-by-value* secara semantik, namun mesin mengeksekusinya secara efisien menggunakan mekanika **Copy-on-Write (CoW)**:
- Ketika sebuah array di-assign ke variabel baru (`$b = $a`), engine tidak menduplikasi memori `arData`. Variabel `$b` dan `$a` menunjuk ke struktur `zend_array` yang sama, dan `refcount` pada header memori dinaikkan (`gc.refcount++`).
- Alokasi memori baru dan kloning bucket fisik hanya dieksekusi secara instan ketika salah satu variabel mencoba memodifikasi data (mutasi).

#### Destructuring Compilation
Operasi `[$a, $b] = $array;` bukan fungsi runtime, melainkan konstruksi bahasa (*language construct*). Compiler mengompilasi baris ini menjadi sekumpulan opcode `ZEND_FETCH_DIM_R` berturut-turut untuk setiap elemen yang dituju, langsung memindahkannya ke ZVAL lokal tanpa overhead function frame call.

### 4. Best Practices & Common Pitfalls

#### Do's
- **Gunakan Spread Operator (`...`) daripada `array_merge`**: Array unpacking (`[...$arr1, ...$arr2]`) dieksekusi langsung pada level byte-code opcode (`ZEND_ROPE_ADD` / internal unpack), melewati overhead pemanggilan fungsi internal C, sehingga lebih cepat dan mendukung analisa statis (static analysis) yang lebih ketat.
- **Validasi Kategori Array dengan `array_is_list()` (PHP 8.1+)**: Sebelum melakukan operasi yang bergantung pada urutan sekuensial (misalnya serialisasi JSON ke format array JSON `[]` bukan objek `{}`), gunakan `array_is_list($arr)` untuk memastikan array adalah *packed array*.
- **Manfaatkan Destructuring pada Foreach**: Ekstraksi langsung elemen tuple/kv di level loop untuk meningkatkan keterbacaan:
  ```php
  foreach ($users as ['id' => $id, 'profile' => ['email' => $email]]) {
      // Langsung akses $id dan $email tanpa intermediate variable
  }
  ```

#### Don'ts
- **Jangan Menggunakan Referensi pada Foreach tanpa `unset()`**:
  ```php
  // SANGAT BERBAHAYA
  foreach ($items as &$item) {
      $item *= 2;
  }
  // Variabel $item masih memegang referensi ke elemen terakhir $items!
  foreach ($items as $item) { 
      // Elemen terakhir $items akan tertimpa di setiap iterasi loop kedua!
  }
  ```
  *Solusi*: Jika terpaksa menggunakan reference loop, panggil `unset($item);` segera setelah loop berakhir. Namun, pendekatan fungsional imutabel dengan `array_map()` jauh lebih direkomendasikan.
- **Jangan Menjalankan `array_merge` di dalam Looping**:
  ```php
  $merged = [];
  foreach ($matrix as $row) {
      $merged = array_merge($merged, $row); // Kompleksitas Memori O(N^2) akibat alokasi ulang CoW terus menerus
  }
  // Gunakan: array_merge(...$matrix);
  ```

#### Edge Cases
- **Key Cast Otomatis (PHP Type Juggling pada Key)**:
  PHP secara otomatis mengonversi tipe data string tertentu menjadi integer jika string tersebut bernilai integer valid:
  ```php
  $arr = [];
  $arr["100"] = "A"; // PHP otomatis mengubah key menjadi integer 100
  $arr[100] = "B";   // Menimpa nilai "A"
  
  $arr["08"] = "C";  // Tetap string "08" (karena bukan integer standar desimal)
  ```
- **Destructuring Key yang Tidak Ada**:
  Melakukan destructuring terhadap kunci yang tidak didefinisikan (`['role' => $role] = $user`) akan memicu `E_WARNING: Undefined array key "role"`. Selalu pastikan nilai default menggunakan ekspresi null-coalescing atau validasi schema payload sebelumnya.

### 5. Tantangan Eksplorasi Mandiri

1. **Investigasi Profil Memori Packed Array**: 
   Tulis skrip PHP CLI yang menginisialisasi array dengan 100.000 elemen numerik berurutan menggunakan `range(0, 99999)`. Ukur penggunaan memori menggunakan `memory_get_usage()`. Kemudian, ubah elemen indeks `$arr[50000] = 'escalated'` atau hapus satu elemen dengan `unset($arr[10])` untuk memaksa *de-optimasi* dari *Packed Array* ke *Hash Array*. Ukur delta memori yang melonjak drastis pasca-mutasi dan jelaskan mengapa de-optimasi tersebut terjadi berdasarkan struktur `arData`.

2. **Implementasi Deep Array Flattener & Key Renamer**:
   Rancang sebuah fungsi murni (*pure function*) rekursif dengan *type declarations* ketat yang menerima array bersarang tak terbatas (arbitrary nested associative array) dan mengembalikan array satu dimensi (*flat array*) dengan representasi *dot-notation* key (misal: `['data' => ['user' => ['name' => 'John']]]` berubah menjadi `['data.user.name' => 'John']`). Implementasikan fungsi ini murni menggunakan manipulasi array imutabel, rekursi, dan *array unpacking*, tanpa memanfaatkan reference atau mutasi *state* di luar fungsi.
