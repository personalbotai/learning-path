# 2. Variabel, Strict Types & Type Juggling

**ID**: M01-L02 | **Duration**: 15 m | **Level**: Semua | **Track**: PHP

## 🎯 Tujuan Pembelajaran
- Menguasai perbedaan fundamental antara *Weak Typing* (Type Juggling) dan *Strict Types* (`declare(strict_types=1)`).
- Menghindari kerentanan keamanan akibat perbandingan longgar (`==`) dan type coercion implisit.
- Memahami tipe skalar (`int`, `float`, `string`, `bool`), union types, dan nullable types di PHP 8.x.

## 📖 Konsep Mendalam

### 1. Mekanisme Type Juggling
Secara default, PHP mengonversi tipe data secara otomatis jika memungkinkan. Perilaku ini berbahaya pada perbandingan longgar:
- Di PHP 7: `0 == "admin"` bernilai `true` (karena `"admin"` di-cast menjadi `0`).
- Di PHP 8+: Angka dikonversi menjadi string, sehingga `0 == "admin"` bernilai `false`, sedangkan `0 == "0"` tetap `true`.

### 2. Mengaktifkan Strict Types
Deklarasi `declare(strict_types=1);` diletakkan di baris paling awal file:
```php
<?php
declare(strict_types=1);

// Fungsi dengan deklarasi tipe ketat
function hitungTotal(int $kuantitas, float $hargaSatuan): float {
    return $kuantitas * $hargaSatuan;
}

// Valid
echo hitungTotal(5, 12500.50) . PHP_EOL;

// TypeError akan dilempar saat compile/runtime jika dikirim string:
try {
    // @phpstan-ignore-next-line
    echo hitungTotal("5", 12500.50); 
} catch (TypeError $e) {
    echo "Pencegahan Berhasil: " . $e->getMessage() . PHP_EOL;
}
```

## ⚠️ Best Practices & Common Pitfalls
- **Selalu Gunakan Identical Operator (`===`)**: Hindari `==` untuk mencegah celah otentikasi atau perbandingan boolean yang tidak disengaja.
- **Scope File `declare(strict_types=1)`**: Directive ini hanya memengaruhi panggilan fungsi yang dilakukan di dalam file tersebut, bukan file tempat fungsi didefinisikan.
