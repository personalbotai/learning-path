# 7. Class, Object & Constructor Property Promotion

**ID**: M02-L01 | **Duration**: 15 m | **Level**: Semua | **Track**: PHP

## 🎯 Tujuan Pembelajaran
- Memahami paradigma OOP modern di PHP 8.2+: Visibility modifiers, typed properties, dan encapsulation.
- Menerapkan *Constructor Property Promotion* untuk mengeliminasi boilerplate kode.
- Menguasai siklus pembuatan instance objek di Zend Engine memori.

## 📖 Konsep Mendalam

Sebelum PHP 8, deklarasi properti, argumen konstruktor, dan assignment harus ditulis 3 kali secara repetitif. Dengan *Constructor Property Promotion*, deklarasi visibilitas langsung disematkan pada parameter konstruktor:

```php
<?php
declare(strict_types=1);

class Pengguna {
    // Constructor Property Promotion
    public function __construct(
        public readonly string $id,
        public string $nama,
        private string $email,
        protected int $usia,
        public array $roles = ['user']
    ) {
        // Validasi invariant domain
        if ($this->usia < 0) {
            throw new InvalidArgumentException("Usia tidak boleh negatif.");
        }
    }

    public function getEmailMasked(): string {
        $parts = explode('@', $this->email);
        return substr($parts[0], 0, 2) . '***@' . $parts[1];
    }
}

$user = new Pengguna(
    id: "usr_9981",
    nama: "Syamsul Bahri",
    email: "syamsul@domain.com",
    usia: 28
);

echo "User ID : {$user->id}" . PHP_EOL;
echo "Nama    : {$user->nama}" . PHP_EOL;
echo "Email   : " . $user->getEmailMasked() . PHP_EOL;
```

## ⚠️ Best Practices & Common Pitfalls
- **Readonly Properties**: Gunakan `readonly` pada identifier unik (seperti ID atau UUID) untuk memastikan nilai tidak dapat diubah setelah konstruksi objek selesai.
- **Type Declaration Wajib**: Selalu definisikan tipe data pada setiap properti agar integritas state objek terjaga.
