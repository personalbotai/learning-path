## 📚 Materi Pembelajaran

### Poin Kunci
- 1. Slice mechanics: pointer, length, capacity (`s = s[:n]`, `s = s[:len(s)-1]`)
- 2. `append` dan memory reallocation, preallocation dengan `make([]T, 0, cap)`
- 3. Copy vs assignment (shared backing array) dan `copy()`
