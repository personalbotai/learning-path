## 🎯 Tujuan Pembelajaran
- Menguasai konsep dasar dan implementasi standar industri untuk **Input/Output Sederhana dan Formatting**.
- Menulis kode Go yang idiomatik, efisien, dan sesuai dengan panduan Go official.
- Menerapkan best practices performa dan keamanan pada aplikasi Go modern.

## 📚 Materi Pembelajaran

### Poin Kunci
- 1. `fmt.Print`, `fmt.Println`, `fmt.Printf` dan `fmt.Scan`
- 2. Verb format: `%d`, `%s`, `%f`, `%v`, `%q`, `%t`
- 3. `strings` dan `strconv` packages untuk manipulasi string dasar

### Penjelasan Mendalam
Dalam pengembangan backend dan sistem modern menggunakan Go, topik **Input/Output Sederhana dan Formatting** memegang peranan krusial dalam menghasilkan kode yang handal, cepat, dan mudah dipelihara. Filosofi Go menekankan kesederhanaan (*simplicity*) dan kejelasan (*clarity*).

1. **Idiom & Konvensi**:
   Go menghindari fitur-fitur kompleks yang membingungkan. Setiap komponen dirancang agar mudah dibaca oleh anggota tim lain.
2. **Kinerja & Keamanan Konkurensi**:
   Dengan compiler yang cepat dan runtime yang dioptimalkan, kode Go mampu menangani beban tinggi dengan alokasi memori yang efisien.
3. **Praktek Terbaik**:
   Pastikan selalu melakukan formatting kode menggunakan `gofmt` atau `goimports`, mengecek potensi kesalahan dengan `go vet`, dan menangani error secara eksplisit tanpa mengabaikannya.

## 💻 Contoh Kode Idiomatik

```go
package main

import (
    "fmt"
    "time"
)

func main() {
    fmt.Printf("=== Pelajaran: %s ===\n", "Input/Output Sederhana dan Formatting")
    fmt.Printf("Waktu eksekusi: %s\n", time.Now().Format(time.RFC3339))
    
    // Implementasi demonstrasi topik
    status := "Sukses dipelajari"
    fmt.Println("Status modul:", status)
}
```
