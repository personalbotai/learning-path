## 💡 Best Practices & Common Pitfalls

### ✅ Rekomendasi (Best Practices)
1. **Gunakan Fitur Java Modern**: Manfaatkan fitur-fitur LTS terbaru (Records, Pattern Matching, Text Blocks) untuk mengurangi boilerplate code.
2. **Gunakan Dependency Injection**: Hindari inisialisasi dependensi secara manual (`new SomeService()`) di dalam controller atau service; gunakan IoC container seperti Spring.
3. **Selalu Handle Exception Secara Spesifik**: Jangan menangkap `catch (Exception e)` umum secara sembarangan tanpa logging yang tepat.

### ⚠️ Hindari (Common Pitfalls)
- Jangan abaikan penutupan resource (database connection, file stream); selalu gunakan pattern `try-with-resources`.
- Hindari shared mutable state tanpa mekanisme sinkronisasi yang terbukti (*thread-safe*).
