## ✨ Features

- 💻 **Live C++20 Code Runner:** Execute C++20 code via in-browser playground compilation (Wandbox GCC 13.2 C++20) with offline fallback simulation.
- 📖 **20 In-Depth Lessons:** Comprehensive curriculum covering pointers, memory architectures, RAII, STL containers, templates, move semantics, and C++20 concepts.
- 🎯 **Deep Technical Quizzes:** Interactive multiple-choice challenges with detailed architectural explanations in Indonesian.
- 🎖️ **Graduation Certificate Generator:** High-resolution Canvas certificate generator with PNG & PDF export — gated strictly to 100% course completion.
- 📱 **PWA & Offline Support:** Service Worker offline caching and Web App Manifest.
- 💾 **Auto-Resume & State Persistence:** Remembers your exact lesson and completion progress in `localStorage`.
- 🌓 **Adaptive Theme & Mobile UX:** Dark/light mode toggle with expandable animated search and responsive navigation.

## 📚 Curriculum Overview

1. **Fondasi Modern C++** — Syntax, `auto`, `constexpr` compile-time evaluation, and structured bindings.
2. **Pointer & Memori** — Pointers vs references, stack vs heap, raw memory hazards, and modern smart pointers (`unique_ptr`, `shared_ptr`).
3. **OOP & Prinsip RAII** — Classes, encapsulation, resource management via RAII, virtual polymorphism, and operator overloading.
4. **STL & Generic Programming** — Sequential containers (`vector`, `array`), associative containers (`map`, `unordered_map`), templates, and lambdas.
5. **Fitur Modern C++20** — Move semantics (`std::move`), Concepts & constraints (`requires`), Ranges pipeline views, and `std::jthread` concurrency.

## 🛠️ Local Development

Clone and run locally with any static file server:

```bash
git clone https://github.com/personalbotai/cpp-learning-path.git
cd cpp-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
