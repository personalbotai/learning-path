## 📖 Materi Lengkap

### 1. Konsep & Arsitektur Mendalam

Secara arsitektural, program komputer dieksekusi secara linear melalui *Instruction Pointer* (Program Counter) yang membaca instruksi mesin dari segmen memori kode (`.text`). Kontrol alur (*Control Flow*) adalah mekanisme untuk membelokkan eksekusi linear tersebut menjadi bercabang (*branching*) atau berulang (*looping*).

#### A. Branching & Kondisional
1. **`if` / `else`:** Evaluasi ekspresi bertipe boolean. Jika kondisi benar, instruksi jump bersyarat dilewati; jika salah, jump dieksekusi ke blok alternatif. C++17 memperkenalkan *init-statement* (`if (init; condition)`), membatasi *scope* variabel sementara hanya pada blok branching tersebut, mencegah polusi variabel pada *enclosing scope*.
2. **`if constexpr` (C++17):** Beroperasi pada level *compile-time*. Kompiler mengabaikan (tidak men-generate assembly untuk) cabang yang kondisinya false. Berbeda dengan evaluasi runtime, cabang yang tidak terpakai tidak memerlukan kelengkapan tipe (*type completeness*) yang valid secara semantik runtime, asalkan lolos sintaks awal.
3. **`switch` Statements:** Struktur pencabangan berbasis nilai diskret (*integral* atau *enumeration*). Alih-alih mengevaluasi kondisi secara berurutan, kompiler sering kali mengoptimasi `switch` menjadi struktur *Jump Table* (array pointer instruksi) jika nilai-nilai *case* terdistribusi padat, menghasilkan kompleksitas percabangan $O(1)$.

#### B. Looping (Perulangan)
1. **Fundamental Loops (`while`, `do-while`, indexed `for`):** Merupakan abstraksi dari kombinasi instruksi assembly label, evaluasi kondisi bersyarat (*conditional branch*), dan *unconditional jump* kembali ke awal label.
2. **Range-based `for` (C++11/C++20):** Merupakan *syntactic sugar* tingkat tinggi yang diekspansi oleh kompiler menjadi pemanggilan iterator:
   ```cpp
   // Konseptual ekspansi C++17
   auto&& __range = ekspresi_kontainer;
   auto __begin = begin_expr; // std::begin(__range)
   auto __end = end_expr;     // std::end(__range)
   for (; __begin != __end; ++__begin) {
       range_declaration = *__begin;
       loop_statement
   }
   ```
   C++20 menambahkan *init-statement* pada range-based `for` (`for (init; decl : expr)`) untuk menyelesaikan masalah *dangling reference* ketika melakukan iterasi terhadap *temporary objects*.

#### C. Interaksi Hardware: Branch Prediction
CPU modern bekerja menggunakan *instruction pipelining*. Agar pipeline tidak terhenti (*stall*), CPU memanfaatkan *Branch Predictor* berbasis hardware (*Branch Target Buffer* / BTB) untuk menebak ke mana arah percabangan sebelum komparasi selesai dievaluasi. 
- **Branch Correct:** Eksekusi berjalan mulus tanpa penundaan.
- **Branch Mispredict:** Terjadi *pipeline flush*—CPU membuang instruksi spekulatif yang salah di pipeline (penalti berkisar 10–20 clock cycles).

### 2. Implementasi & Contoh Kasus Nyata

Contoh berikut menunjukkan pemrosesan paket data jaringan bervolume tinggi (*high-throughput parsing*) menggunakan modern C++ idiom: `if` dengan *init-statement*, `[[likely]]` / `[[unlikely]]` attributes (C++20), serta pattern matching menggunakan `switch`.

```cpp
#include <iostream>
#include <vector>
#include <cstdint>
#include <optional>
#include <string_view>

enum class PacketType : uint8_t {
    Heartbeat = 0x01,
    Data      = 0x02,
    Error     = 0x03,
    Shutdown  = 0xFF
};

struct Packet {
    PacketType type;
    uint32_t sequence_id;
    std::vector<uint8_t> payload;
};

// Simulasi parser stream paket
std::optional<Packet> parse_packet_header(uint8_t raw_byte, uint32_t seq) {
    switch (raw_byte) {
        case static_cast<uint8_t>(PacketType::Heartbeat):
            return Packet{PacketType::Heartbeat, seq, {}};
        case static_cast<uint8_t>(PacketType::Data):
            return Packet{PacketType::Data, seq, {0xDE, 0xAD, 0xBE, 0xEF}};
        case static_cast<uint8_t>(PacketType::Error):
            return Packet{PacketType::Error, seq, {0x00}};
        case static_cast<uint8_t>(PacketType::Shutdown):
            return Packet{PacketType::Shutdown, seq, {}};
        default:
            return std::nullopt; // Protokol korup
    }
}

int main() {
    std::vector<uint8_t> network_buffer = {0x01, 0x02, 0x02, 0xAA, 0x01, 0xFF};

    // 1. C++20 Range-based for loop dengan init-statement
    for (uint32_t seq_counter = 0; auto byte : network_buffer) {
        
        // 2. C++17 If statement dengan initialization
        if (auto packet = parse_packet_header(byte, ++seq_counter); packet.has_value()) {
            
            // 3. Pattern evaluation dengan jump optimization
            switch (packet->type) {
                // Memberikan hint ke branch predictor tentang jalur eksekusi tersering (C++20)
                [[likely]] case PacketType::Data:
                    std::cout << "[Seq " << packet->sequence_id << "] Data Payload Processed (" 
                              << packet->payload.size() << " bytes)\n";
                    break;

                case PacketType::Heartbeat:
                    std::cout << "[Seq " << packet->sequence_id << "] Keep-Alive Acknowledged\n";
                    break;

                [[unlikely]] case PacketType::Error:
                    std::cerr << "[Seq " << packet->sequence_id << "] Alert: Malformed payload\n";
                    break;

                [[unlikely]] case PacketType::Shutdown:
                    std::cout << "[Seq " << packet->sequence_id << "] Teardown Signal Received. Halting.\n";
                    return 0; // Guard return
            }
        } else {
            // Jalur anomali
            std::cerr << "[Seq " << seq_counter << "] Critical Error: Invalid packet magic byte: 0x" 
                      << std::hex << static_cast<int>(byte) << std::dec << "\n";
            continue;
        }
    }

    return 0;
}
```

### 3. Cara Kerja di Balik Layar (Under the Hood)

#### A. Eksekusi & Instruksi Assembly
Kompiler mengonversi kontrol alur ke set instruksi arsitektur target (contoh: x86-64):
- Struktur `if-else` diterjemahkan menjadi pasangan instruksi `test`/`cmp` diikuti instruksi *conditional jump* seperti `jne` (*jump if not equal*), `je` (*jump if equal*), atau `jg` (*jump if greater*).
- **Jump Table vs. Binary Search:** 
  Pada `switch`, jika rentang *case* rapat (misal nilai 1, 2, 3, 4), kompiler membuat tabel pointer statis di segmen `.rodata`. Kompiler hanya memvalidasi rentang input, lalu melakukan dereferensi register langsung: `jmp *rax`. Ini adalah lompatan $O(1)$. Jika *case* tersebar jarang (misal: 1, 1000, 999999), kompiler menurunkannya menjadi *binary search tree* via rantai `cmp` dan `je` ($O(\log N)$).

#### B. Destruksi Objek (RAII) & Stack Unwinding
Ketika alur eksekusi meninggalkan sebuah *scope* via `break`, `continue`, `return`, atau `goto`:
- Kompiler secara deterministik menyisipkan destruktor untuk semua objek lokal yang telah terkonstruksi di dalam *scope* tersebut sebelum instruksi `jmp` dieksekusi.
- `goto` dilarang oleh standar C++ melompati deklarasi variabel bertipe non-trivial yang belum diinisialisasi dalam *scope* yang sama, karena akan merusak *invarian objek* pada *stack frame*.

#### C. Trade-offs: Branching vs. Branchless
- **Conditional Branching:** Menghemat instruksi aritmatika jika cabang di-skip, tetapi memiliki risiko *Branch Misprediction Penalty* yang merusak *pipeline* CPU.
- **Branchless Logic:** Mengganti percabangan kondisional dengan manipulasi bitwise atau *Conditional Move* (`cmov` pada x86). Instruksi `cmov` mengeksekusi kedua komputasi secara paralel/spekulatif dan memilih hasil tanpa melompat.
  ```cpp
  // Branchy
  int max_val = (a > b) ? a : b; // Tergantung branch predictor

  // Branchless (via instruksi CMOV di level assembly)
  // Menghilangkan resiko branch misprediction sepenuhnya dengan trade-off konsumsi ALU
  ```

### 4. Best Practices & Common Pitfalls

#### Do's
1. **Manfaatkan Init-Statement:** Selalu gunakan `if (init; condition)` untuk membatasi ruang lingkup variabel pembantu, menjaga *encapsulation*, dan meminimalisir kesalahan mutasi tidak sengaja di luar blok terkait.
2. **Manfaatkan `[[fallthrough]]` Secara Eksplisit:** Jika sengaja membiarkan alur *case* pada `switch` lolos ke *case* berikutnya (*fall-through*), tandai dengan atribut `[[fallthrough]];` guna menonaktifkan peringatan (*warning*) kompiler dan mengonfirmasi maksud kode secara eksplisit ke insinyur lain.
3. **Iterasi Menggunakan `const auto&`:** Pada range-based `for`, gunakan `for (const auto& item : container)` secara default guna mencegah *copy construction* yang membebani alokasi memori heap, kecuali tipe data tersebut bernilai primitif/trivial (`int`, `char`, `float`).

#### Don'ts
1. **Memodifikasi Kontainer saat Iterasi (Iterator Invalidation):** Jangan menambah (`push_back`) atau menghapus (`erase`) elemen dari kontainer (`std::vector`, `std::unordered_map`) saat sedang diiterasi di dalam loop secara langsung tanpa memperbarui status iterator. Hal ini memicu *Undefined Behavior* karena realokasi memori internal kontainer.
2. **Pengabaian Branching di Hot Path:** Jangan meletakkan rantai `if-else` panjang di dalam iterasi kritis frekuensi tinggi jika prediksinya bersifat acak (*non-deterministic*). Pertimbangkan teknik *lookup table* atau *data-oriented design*.

#### Edge Cases
- **Unsigned Loop Underflow:**
  ```cpp
  // BUG FATAL: Loop tak hingga (Infinite Loop)
  // Ketika i bernilai 0, ekspresi --i menghasilkan nilai maksimum unsigned (misal: 18446744073709551615 untuk uint64_t)
  for (size_t i = 10; i >= 0; --i) {
      process(i);
  }
  ```
  *Mitigasi:* Gunakan signed integer untuk loop mundur, atau iterasi dari 0 hingga N lalu sesuaikan indeks secara manual, atau gunakan idiom:
  ```cpp
  for (size_t i = 10; i-- > 0; ) {
      process(i);
  }
  ```
- **Dangling Reference pada Temporary Objects (Pre-C++23):**
  ```cpp
  // Undefined Behavior sebelum C++23
  for (auto x : get_temporary_struct().get_vector_reference()) { ... }
  ```
  Objek temporary yang dihasilkan `get_temporary_struct()` langsung dihancurkan (*lifetime ends*) tepat setelah ekspresi inisialisasi range selesai, meninggalkan referensi kontainer dalam status *dangling*. Pada C++20, selesaikan dengan *init-statement*:
  ```cpp
  for (auto obj = get_temporary_struct(); auto x : obj.get_vector_reference()) { ... }
  ```
