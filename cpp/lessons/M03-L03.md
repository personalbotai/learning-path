## 📖 Materi Lengkap

### 1. Konsep & Arsitektur Mendalam

Operator overloading adalah mekanisme polimorfisme statis (compile-time polymorphism) dalam C++ yang memungkinkan tipe data buatan pengguna (*user-defined types* seperti `class` atau `struct`) mendefinisikan ulang perilaku operator bawaan (seperti `+`, `-`, `*`, `[]`, `<<`, hingga `<=>`).

Secara fundamental, operator dalam C++ hanyalah representasi *syntactic sugar* dari pemanggilan fungsi biasa. Ekspresi:
```cpp
a + b;
```
Diterjemahkan oleh compiler menjadi salah satu dari dua bentuk berikut:
1. **Member function call**: `a.operator+(b)`
2. **Non-member / Free function call**: `operator+(a, b)`

#### Aturan & Batasan Fundamental
Compiler C++ menetapkan aturan ketat terkait modifikasi operator:
1. **Tidak dapat membuat operator baru**: Simbol seperti `**`, `<>`, atau `%%` tidak dapat dibuat.
2. **Presedensi dan Asosiatif tidak berubah**: Operator `*` akan selalu memiliki presedensi lebih tinggi daripada `+`, terlepas dari definisi overload-nya.
3. **Jumlah operan (arity) tetap**: Operator uner (`!`, `~`, `++`) tetap menerima satu operan; operator biner (`+`, `==`) tetap menerima dua operan.
4. **Operator yang tidak dapat di-overload**:
   - `.` (Member access)
   - `.*` (Pointer to member)
   - `::` (Scope resolution)
   - `?:` (Ternary conditional)
   - `sizeof`, `alignof`, `typeid`, `noexcept`
5. **Setidaknya satu operan harus user-defined type**: Anda tidak dapat mengubah perilaku `1 + 2` bawaan integer primitif.

#### Member vs Non-Member (Canonical Form)
Kapan harus menggunakan *member function* versus *free function*?
- **Wajib sebagai Member**: `operator=`, `operator[]`, `operator()`, `operator->`. Standar C++ mewajibkan ini untuk menjamin bahwa operan sebelah kiri (*lvalue*) selalu valid dan terdefinisi pada tipe terkait.
- **Wajib sebagai Non-Member**: `operator<<` dan `operator>>` (I/O streams) karena operan kiri adalah stream (`std::ostream` / `std::istream`), bukan objek kelas kita.
- **Sangat Disarankan sebagai Non-Member**: Operator biner simetris (`+`, `-`, `*`, `==`). Jika diimplementasikan sebagai member function, konversi implisit hanya berlaku pada operan kanan (`obj + 5` valid, tetapi `5 + obj` gagal dikompilasi). Dengan free function, compiler dapat menerapkan konversi implisit pada kedua sisi via *Argument-Dependent Lookup (ADL)*.

### 2. Implementasi & Contoh Kasus Nyata

Berikut adalah implementasi kelas `Vector2D` matematis dan ringkas, mencakup operator aritmatika, I/O stream, subscripting, dan modern C++20 Spaceship Operator (`<=>`).

```cpp
#include <iostream>
#include <compare>
#include <cmath>
#include <stdexcept>

class Vector2D {
private:
    double x_{0.0};
    double y_{0.0};

public:
    // Konstruktor
    constexpr Vector2D() noexcept = default;
    constexpr Vector2D(double x, double y) noexcept : x_(x), y_(y) {}

    // Getter
    [[nodiscard]] constexpr double x() const noexcept { return x_; }
    [[nodiscard]] constexpr double y() const noexcept { return y_; }

    // Magnitude kuadrat (untuk komparasi performa tinggi tanpa sqrt)
    [[nodiscard]] constexpr double length_squared() const noexcept {
        return x_ * x_ + y_ * y_;
    }

    // 1. Compound Assignment Operator (Member Function)
    // Selalu kembalikan referensi ke *this untuk mendukung chaining: (v1 += v2) += v3;
    Vector2D& operator+=(const Vector2D& rhs) noexcept {
        x_ += rhs.x_;
        y_ += rhs.y_;
        return *this;
    }

    Vector2D& operator-=(const Vector2D& rhs) noexcept {
        x_ -= rhs.x_;
        y_ -= rhs.y_;
        return *this;
    }

    Vector2D& operator*=(double scalar) noexcept {
        x_ *= scalar;
        y_ *= scalar;
        return *this;
    }

    // 2. Subscript Operator (Read-write & Read-only variants)
    double& operator[](std::size_t index) {
        if (index == 0) return x_;
        if (index == 1) return y_;
        throw std::out_of_range("Vector2D index out of bounds (only 0 or 1 valid)");
    }

    const double& operator[](std::size_t index) const {
        if (index == 0) return x_;
        if (index == 1) return y_;
        throw std::out_of_range("Vector2D index out of bounds (only 0 or 1 valid)");
    }

    // 3. Unary Minus Operator (Negasi)
    Vector2D operator-() const noexcept {
        return Vector2D{-x_, -y_};
    }

    // 4. Equality Operator (C++20 otomatis menurunkan operator!= dari operator==)
    bool operator==(const Vector2D& rhs) const noexcept {
        constexpr double EPSILON = 1e-9;
        return std::abs(x_ - rhs.x_) < EPSILON && std::abs(y_ - rhs.y_) < EPSILON;
    }

    // 5. C++20 Three-Way Comparison (Spaceship Operator)
    // Membandingkan vektor berdasarkan panjangnya (magnitude)
    auto operator<=>(const Vector2D& rhs) const noexcept {
        return length_squared() <=> rhs.length_squared();
    }

    // 6. Non-Member Binary Arithmetic Operators via Hidden Friends
    // Diimplementasikan berbasis compound assignment untuk menjamin konsistensi
    friend Vector2D operator+(Vector2D lhs, const Vector2D& rhs) noexcept {
        lhs += rhs; // lhs di-pass by-value, bertindak sebagai copy lokal
        return lhs; // Mengoptimalkan NRVO/RVO
    }

    friend Vector2D operator-(Vector2D lhs, const Vector2D& rhs) noexcept {
        lhs -= rhs;
        return lhs;
    }

    // Mendukung skalar di kanan: vec * 2.0
    friend Vector2D operator*(Vector2D lhs, double scalar) noexcept {
        lhs *= scalar;
        return lhs;
    }

    // Mendukung skalar di kiri: 2.0 * vec (simetri komutatif)
    friend Vector2D operator*(double scalar, Vector2D rhs) noexcept {
        return rhs * scalar; 
    }

    // 7. Stream Insertion & Extraction (Harus Free/Friend Function)
    friend std::ostream& operator<<(std::ostream& os, const Vector2D& vec) {
        os << "Vector2D(" << vec.x_ << ", " << vec.y_ << ")";
        return os; // Return stream referensi untuk chaining
    }
};

int main() {
    Vector2D v1{3.0, 4.0};
    Vector2D v2{1.0, 2.0};

    // Aritmatika biner simetris
    Vector2D v3 = v1 + v2;
    Vector2D v4 = 2.5 * v3; // Skalar di sisi kiri bekerja berkat free-friend operator

    std::cout << "v3: " << v3 << "\n";
    std::cout << "v4: " << v4 << "\n";

    // Subscripting
    v4[0] = 100.0;
    std::cout << "v4 modifikasi: " << v4[0] << ", " << v4[1] << "\n";

    // Perbandingan menggunakan spaceship operator (<=>)
    if (v1 > v2) {
        std::cout << "Magnitude v1 lebih besar daripada v2\n";
    }

    return 0;
}
```

### 3. Cara Kerja di Balik Layar (Under the Hood)

#### Eksekusi & Runtime: Name Mangling & Binding
Di level assembly dan object file, konsep *operator* tidak ada. Compiler mengubah tanda operator menjadi fungsi biasa menggunakan mekanisme **Name Mangling**.

Misalnya pada arsitektur Itanium ABI (digunakan oleh GCC dan Clang di Linux/macOS):
- `Vector2D::operator+=(const Vector2D&)` di-mangle menjadi `_ZN8Vector2DaSERKS_`
- Operator biner non-member `operator+(Vector2D, const Vector2D&)` di-mangle menjadi `_Zpl8Vector2DRKS_`

Karena operator hanyalah fungsi biasa, resolusi pemanggilan operator diselesaikan sepenuhnya pada saat kompilasi (*compile-time overload resolution*). Jika sebuah fungsi operator di-*inline* (seperti `constexpr` atau friend function di dalam class body), compiler sering kali mengeliminasi seluruh overhead fungsi, mengubah operasi ke instruksi SIMD atau register CPU langsung tanpa overhead pemanggilan stack frame.

#### Alokasi Memori & RVO (Return Value Optimization)
Pola implementasi operator biner:
```cpp
friend Vector2D operator+(Vector2D lhs, const Vector2D& rhs) {
    lhs += rhs;
    return lhs;
}
```
Teknik di atas dinamakan pola **Canonical Pass-by-Value with Compound Assignment**.
1. Compiler meng-copy operan kiri ke parameter `lhs` (atau langsung melakukan *move* jika operan kiri adalah rvalue seperti ekspresi sementara `(a + b) + c`).
2. Operasi mutasi dilakukan pada variabel lokal `lhs`.
3. Saat dikembalikan, teknik **Named Return Value Optimization (NRVO)** atau **Copy Elision** (wajib sejak C++17) mengonstruksi nilai kembalian langsung di ruang memori caller tanpa alokasi memori tambahan maupun copy/move redundant.

#### Trade-offs: Canonical Pattern vs In-place Performance
Menggunakan idiom `operator+` berbasis `lhs by-value` + `+=` mengurangi duplikasi kode secara drastis (*Single Responsibility*). Namun, untuk tipe data berat yang mengalokasikan heap memory dinamis (seperti matriks besar `BigInt` atau `Matrix`), pendekatan ini dapat memaksa satu kali alokasi copy. Untuk kelas-kelas tipe alokasi heap berat, sering kali dibutuhkan overload tambahan khusus untuk Rvalue Reference:
```cpp
Matrix operator+(Matrix&& lhs, const Matrix& rhs) {
    lhs += rhs; // Reuse memory buffer dari rvalue
    return std::move(lhs);
}
```

### 4. Best Practices & Common Pitfalls

#### Do's
- **Jaga Semantik Alami**: Pastikan `+` berarti penambahan, `==` berarti kesetaraan, `*` berarti perkalian atau dereference pointer. Mengubah arti simbol demi kenyamanan sintaksis (misal memakai `+` untuk menambahkan user ke database) merusak prediktabilitas kode (*Principle of Least Astonishment*).
- **Implementasikan Pasangan Logis**: Jika mendefinisikan `+=`, selalu definisikan `+`. Jika mendefinisikan `<`, sediakan `<`, `>`, `<=`, `>=`, `==`, `!=` (Di C++20, cukup gunakan `operator<=>` dan `operator==`).
- **Gunakan Idiom Hidden Friend**: Definisikan operator biner non-member langsung di dalam *class definition* menggunakan kata kunci `friend`. Fungsi ini tidak mencemari global namespace, hanya ditemukan via ADL (*Argument-Dependent Lookup*), dan memangkas waktu kompilasi (*compile time*).
- **Kembalikan Tipe yang Benar**:
  - `operator=` dan `operator+=`: Kembalikan `T&` (`*this`).
  - `operator+`, `-`, `*`: Kembalikan objek baru `T` (by-value).
  - `operator==`, `<`, `<=>`: Kembalikan boolean atau tipe comparison category (`std::strong_ordering`).

#### Don'ts
- **Jangan Meng-overload `operator&&`, `operator||`, dan `operator,` (Comma)**:
  Dalam bahasa C++ bawaan, `&&` dan `||` memiliki sifat **Short-Circuit Evaluation** (jika operan kiri salah, operan kanan tidak dievaluasi). Saat Anda meng-overload operator ini menjadi fungsi `operator&&(a, b)`, kedua argumen akan dievaluasi sebelum fungsi dipanggil! Hal ini memecah semantik dasar bahasa dan sering menyebabkan bug pointer null.
- **Jangan Mengembalikan Referensi ke Local Stack Object**:
  ```cpp
  // FATAL BUG: Mengembalikan dangling reference!
  Vector2D& operator+(const Vector2D& a, const Vector2D& b) {
      Vector2D result = a;
      result += b;
      return result; // undefined behavior saat diakses caller
  }
  ```
- **Jangan Lupa `const` Qualifier**: Operator seperti `operator[]` atau operator komparasi harus memiliki versi `const` agar dapat dipanggil pada objek `const`.

#### Edge Cases
- **Self-Assignment (`operator=`)**: Jika membuat copy/move assignment manual untuk resource mentah, selalu antisipasi `v = v;`. Gunakan idiom **Copy-and-Swap** untuk mencapai jaminan exception-safety yang kuat (*Strong Exception Guarantee*).
- **Prefix vs Postfix Increment/Decrement**:
  - Prefix (`++v`): `Vector2D& operator++();` (menaikkan nilai, kembalikan `*this`).
  - Postfix (`v++`): `Vector2D operator++(int);` (menerima dummy parameter integer `int`, membuat copy nilai lama, menaikkan nilai objek saat ini, lalu mengembalikan copy lama by-value). Postfix selalu memiliki penalti performa pembuatan copy.

### 5. Tantangan Eksplorasi Mandiri

1. **Implementasi Smart Pointer Minimalis (`UniquePtr`)**:
   Buat kelas template `UniquePtr<T>` yang mengelola memori heap. Lakukan overload pada:
   - `operator*` untuk mendereferensikan pointer (mengembalikan `T&`).
   - `operator->` untuk mengakses member pointer (mengembalikan `T*`).
   - Explicit `operator bool()` untuk memeriksa apakah pointer bernilai `nullptr` atau valid dalam pernyataan `if (ptr)`.
2. **Matrix Arithmetic & Exception Safety**:
   Buat kelas `Matrix` 2D dinamis berbasis `std::vector<double>`. Implementasikan `operator+=` dan `operator+`. Pastikan Anda melempar exception `std::invalid_argument` jika dimensi kedua matriks tidak sama, dan pastikan status matriks asal tidak korup (*Strong Exception Safety Guarantee*).
3. **Analisis Assembly Operator Overload**:
   Buka [Compiler Explorer (godbolt.org)](https://godbolt.org/). Masukkan implementasi `Vector2D operator+` berbasis member function biasa versus non-member friend function dengan optimasi `-O3`. Amati apakah compiler menghasilkan assembly instruksi vektorisasi (SSE/AVX) yang sama.
